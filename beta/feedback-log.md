## 🔐 Beta Testing Guidelines

### For Beta Testers:

1. **Test Thoroughly:** Try to break things!
2. **Document Everything:** Screenshots help a lot
3. **Be Specific:** "Button doesn't work" vs "Add Card button shows spinner indefinitely"
4. **Test Edge Cases:** Large amounts, special characters, long names
5. **Try Different Browsers:** Chrome, Safari, Firefox
6. **Test on Mobile:** iOS and Android if possible

### Reporting Issues:

Use this format:

```
**Issue Title:** Brief description

**Steps to Reproduce:**
1. Go to...
2. Click on...
3. See error

**Expected Behavior:**
Should show...

**Actual Behavior:**
Shows error...

**Environment:**
- Browser: Chrome 120
- OS: macOS Sonoma
- Screen: Desktop

**Screenshot:**
[Attach if possible]

**Severity:** Critical/High/Medium/Low
```
